# 谷歌地址守卫

在 SillyTavern 中切换 Google AI Studio 和 Claude / OpenAI 兼容源时，自动处理误留在谷歌代理地址末尾的 `/v1`。

## 安装

酒馆 → 扩展 → 安装扩展，粘贴：

```text
https://github.com/qijiu79-79/SillyTavern-Google-URL-Guard
```

安装后刷新页面。在扩展面板找到「谷歌地址守卫」，默认启用。目标版本：SillyTavern 1.19.0 及以上；其他版本/第三方分支未验证。

## 怎样起作用

- 只处理 **Google AI Studio**（内部来源 `makersuite`）的聊天生成与连接/模型列表检查请求。
- 发送前将 `https://example.com/v1` 修正为 `https://example.com`。`/v1/` 和重复的末尾 `/v1` 也会处理。
- 保留路径前缀、查询参数和片段；不删除 `/v1beta`、中间路径中的 `/v1` 或别的版本号。
- 以每个请求携带的来源为准，不靠模型名字判断，不会因界面切换而误改正在发送的 Claude 请求。
- **地址输入框仍可能显示 `/v1`，这是刻意保留的。** 实际谷歌请求会自动修正，无需手动删除。插件不保存或覆盖共享地址、代理预设、连接配置和 API 密钥，因此切回 OAI 不会缺少 `/v1`。
- 不增加模型调用、不重试聊天请求、不上传聊天或配置，不记录地址和密钥。修正计数只存在当前页面内存中。

这是一层请求保护，不宣称已修复导致原设置变化的根因。不支持其他插件直接访问第三方服务、绕过酒馆后端的请求，也不改变图像、嵌入等独立功能的接口。

## 手机与电脑

访问同一台酒馆、同一账户时，安装一次即可；**所有已经打开的设备页面都需要刷新一次**。不同酒馆实例需要分别安装。没有加载插件的旧标签页不会获得保护，但它重新保存的旧地址也不会影响已加载本插件的页面发送谷歌请求。

## 一键更新

- 支持酒馆「管理扩展」原生更新。插件面板只有一个更新按钮：先点「检查更新」，发现新版后变为「一键更新」。
- 检查只读取 Git 状态，不下载新版、不调用 AI。一键更新使用酒馆自己的更新接口，不执行自制安装命令。
- 只更新当前插件目录，自动区分当前用户安装与所有用户安装，并核对仓库来源和更新后的提交。
- 面板内更新成功后自动刷新。正在生成、有聊天草稿、编辑框/弹窗打开、页面在后台时暂缓；其他面板编辑过内容时请先保存，再点「刷新生效」。
- 更新失败或超时不会自动刷新；结果不确定时只核对状态，不自动重复更新。
- 手动下载 ZIP 不带 Git 信息，不能一键更新，请使用仓库链接安装。
- 原生「管理扩展」中更新后的刷新行为由酒馆自己管理；本插件的安全自动刷新针对面板内更新。

## 停用

取消「启用」立即停止地址修正；在扩展管理禁用后刷新也可完全卸载运行逻辑。停用不需要恢复任何源地址，因为插件从未改写它们。

## 开发与检查

没有构建步骤、没有 npm 运行依赖。`npm test` 执行 Node 内置测试。

实现使用酒馆的 `CHAT_COMPLETION_SETTINGS_READY` 事件，另为同源的 `/api/backends/chat-completions/status` 和 `/generate` 加有限的 JSON 请求保护。保留原请求头、取消信号、凭据选项和响应流，不包装响应或吞掉网络错误。

更新前请保留自己对插件源码的修改；插件不强制覆盖有冲突的 Git 工作区。
